- 采用 Kustomize 管理 Kubernetes 资源，通过 `deploy/k8s/kustomization.yaml` 聚合 Namespace、RBAC、ConfigMap、Secret、PVC 及 Backend/Worker/Frontend 组件。
- 实现 API 与 Worker 分离的生产架构：Backend 负责任务调度与产物下载，Worker 负责并发执行构建任务，两者通过共享 RWX 存储卷和 PostgreSQL 数据库协同工作。
- 提供标准化的来源环境（Source Environments）定义，通过 `source-environments.yaml` 声明 dev/test 环境的中间件、基础平台及业务命名空间结构，并配套渲染安装脚本。
- 集成安全基线：K8s 部署强制非 Root 运行、禁用特权升级、配置 Seccomp 策略，并通过 NetworkPolicy 限制仅开放必要的内部通信、DNS 及外部数据库出口。
