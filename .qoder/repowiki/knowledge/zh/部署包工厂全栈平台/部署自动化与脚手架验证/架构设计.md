- 采用 Shell (Bash) 与 Python 混合架构：Shell 负责 Docker/K8s 流程编排，Python 处理复杂模板渲染与逻辑校验。
- 核心组件包括：镜像生命周期管理 (`build/push-images`)、K8s 资源生成器 (`render-deploy/source-environments`)、以及基于后端服务的脚手架 E2E 验证器 (`validate_microservice_scaffolds.py`)。
