- 应用入口：`main.py` 创建 FastAPI 实例，挂载业务路由并暴露 `/health`、`/health/ready`、`/metrics` 端点。
- 配置层：`settings.py` 基于环境变量加载不可变配置（数据库、输出目录、并发限制、执行模式等）。
- 安全层：`auth.py` 实现基于 API Token 的依赖注入鉴权，支持 Bearer Header、自定义 Header 及特定路径的查询参数。
- 可观测性：`metrics.py` 渲染 Prometheus 格式指标；`readiness.py` 聚合数据库、元数据存储、输出目录及镜像导出环境的就绪状态。
- 任务执行：`worker.py` 作为独立进程运行，通过轮询数据库获取待处理任务并调用 `PackageTaskExecutor` 执行构建逻辑。
