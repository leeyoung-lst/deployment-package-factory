- **技术栈**：采用 Vite 7 + React 19 + TypeScript 5.9，UI 组件库为 Ant Design 6.4。
- **分层结构**：`src/api/` 封装 HTTP 客户端与业务接口；`src/views/hooks/` 实现自定义 Hook（如 `useDeploymentPackageController`）处理状态逻辑与副作用；`src/views/components/` 存放细粒度 UI 组件；`src/views/*.tsx` 为顶层视图入口。
- **状态管理**：采用“控制器模式”，将表单实例、自定义状态 Hook 和业务逻辑 Hook 聚合在 Controller Hook 中，通过 Props 下发至展示层组件。
- **构建优化**：`vite.config.ts` 配置了手动分块策略，将 `react`、`remixicon` 等第三方库拆分为独立 Chunk。
- **运行时配置**：支持通过 `window.__DEPLOYMENT_PACKAGE_FACTORY_CONFIG__` 注入 API 地址与 Token，适配容器化部署环境。
